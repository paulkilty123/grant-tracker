Plain-text reference for the Grant Tracker "Confirm signup" email.

NOTE: Supabase's per-template editor takes a single HTML body — there is no
separate plain-text field in the dashboard, so the HTML template is what sends.
Most clients auto-derive a text view from clean HTML. This text version is kept
for reference and for use if a true multipart/alternative text part is ever
configured at the Resend/SMTP layer.
