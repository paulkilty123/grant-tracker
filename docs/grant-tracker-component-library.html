3. Buttons

Four tiers of emphasis. Use the right one for the job.

Primary — lime green

For hero CTAs and conversion moments. Sparingly. "Apply to join", "Finish & see my matches", "Add to pipeline", "Save changes".

Utility — deep forest green

For repeated utility actions that shouldn't shout. "Continue", "Search", "Done", "Apply at [funder]".

Secondary — outlined neutral

Supporting actions alongside primary. "Save for later", "Cancel", "Visit funder".

Tertiary — faint outlined

Lowest emphasis on a card. "Visit funder" when Save and Add-to-pipeline are also present.

Text / link

For inline links like "Show all 2,847 grants", "View all deadlines →", "See all matches →".

Danger — in danger-zone sections only

17. Implementation notes

Modals

All modals use rgba(23, 52, 4, 0.4) — deep forest green at 40% opacity — for the backdrop. Never generic black. Max-width 640px. 16px radius. Follows the same header/body/footer structure as the Pipeline edit modal.

Sticky footers

Used on Profile and Notifications settings pages. Fixed bottom, full width, white bg, 0.5px top border, light shadow 0 -2px 10px rgba(0,0,0,0.03). Status indicator left ("All changes saved" with green check), actions right.

Sidebar

Deep forest green background #173404. Pale-green nav labels. Active state: slightly lighter green panel #27500A with pale green text and lime icon. Sidebar is HIDDEN during the entire onboarding flow (only the wordmark shows top-left).

Page backgrounds

All pages use #FAFAF7 as the main background. Card surfaces are white #fff. Never use pure white as page background.

Hover states

Drag handles and remove (× or ⋮) actions on pipeline cards should have opacity 0 by default and 0.6–1 on hover. Don't show them persistently — creates visual noise.

Never-do list

  • Never use pure red. Coral (for declined/urgent) is the only red-family colour in the system.
  • Never use blue outside Social Investment contexts. A blue location pin would collide with the system.
  • Never use amber for counts or progress — amber is reserved for helper and warning states.
  • Never use DM Serif Display outside the two approved places (invite welcome + marketing About quote).
  • Never use generic black modal backdrops — always deep forest green at 40% opacity.
  • Never show a "0" as a dashboard value. Use friendly empty-state copy instead.
