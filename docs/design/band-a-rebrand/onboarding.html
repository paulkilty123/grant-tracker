Two copy problems on this page, both launch-timing

"Founding cohort, you're in" is true today and wrong from September. Anyone arriving through public signup is not a founding cohort member, and telling them they are makes the rest of the page less believable. This needs either a condition on cohort membership or a neutral replacement — "Let's get you set up" works for everyone.

The name fallback produces "Welcome, there." — firstName() returns the string 'there' when it can't find a name, and the template renders Welcome, {name}. That reads as a typo. Falling back to a nameless "Welcome." would be cleaner. Small, but it's on the first screen.

Three recommendations on the wizard

1. Add "Step 3 of 6" as text beside the dots. Six dots where the active one is wider is elegant, but it's the only progress signal and it's purely visual — a screen reader gets nothing, and it's hard to count at a glance. The text costs one line and makes the dots decorative rather than load-bearing. This is the change I'd argue hardest for.

2. Every confidence state needs a shape, not just a colour. Currently confident/uncertain/missing are carried by green, amber and a dashed border. The dashed border survives greyscale; the green/amber distinction doesn't. Adding the tick and warning glyphs above fixes it without changing the logic in fieldConf().

3. The card should stay 720px and stay a card. It's the one place in Band A where a wider container is right — the review step has four fields and the sector step has ten chips, and squeezing those into the 436px auth card would push everything below the fold. No change needed, just don't let the auth card width leak across.

What I have not designed

The wizard file is 2,147 lines and has seven states; I've drawn four. Not covered: the manual fallback branch (step 2's alternative when URL extraction fails), beneficiaries, location, the "Finding your matches…" loading state, per-field inline editing, and mobile. The four above establish the language — shell, progress, confidence, chips, result rows — and the rest inherit it, but somebody should check that claim against the real file rather than take my word for it.
