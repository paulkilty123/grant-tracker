Sidebar — the alpha bump is load-bearing

Forest #173404 is darker than deep #1D3C3E, so every alpha-based colour loses contrast when the background lightens. Swapping only the background quietly drifts the whole sidebar down. Computed, not estimated:

ElementOn forest todayOn deep, alpha unchangedOn deep, proposed
Nav label, inactive7.04:16.29:17.40:1 @ .80
Nav icon, inactive4.76:14.39:16.07:1 @ .70
Brand / active label12.18:110.55:110.55:1
Accent (lime → sage)7.03:1—6.41:1

Nothing fails either way — icons are non-text UI at a 3:1 floor — but the drift is the wrong direction and invisible without measuring. Change the alphas in the same commit as the background, or don't change the background.
